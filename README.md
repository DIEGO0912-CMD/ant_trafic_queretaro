# Simulación de Tráfico en Querétaro con Algoritmo de Colonia de Hormigas

Este proyecto simula la optimización del tráfico urbano en Querétaro, México, utilizando un algoritmo inspirado en el comportamiento de las hormigas.

## 🔧 Requisitos

```bash
pip install -r requirements.txt
```

## ▶️ Uso

```bash
python main.py
```

Al finalizar, se genera un archivo `ruta_simulada.html` con la mejor ruta encontrada.

## 🧠 Algoritmo

Se utiliza un enfoque de colonia de hormigas (ACO) donde las hormigas depositan feromonas en rutas eficientes y exploran nuevas opciones, evitando la congestión simulada.
